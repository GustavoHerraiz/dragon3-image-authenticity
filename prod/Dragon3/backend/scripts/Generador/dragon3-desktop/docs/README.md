# 🐉 Dragon3 - Marca de Agua Forense

**Sistema profesional de sellado forense de imágenes para fotógrafos.**

---

## 📖 ¿Qué es Dragon3?

Dragon3 es un sistema de **marca de agua forense** diseñado para proteger el trabajo de fotógrafos profesionales. 
Combina técnicas de **esteganografía en el dominio de la frecuencia (DCT)** y **geometría espiral (Vogel)** 
para crear un sello invisible, resistente y verificable.

---

## 🎯 Características principales

- **🔒 Sello invisible en píxeles** (Stardust + Vogel)
- **📝 Metadatos forenses** (Técnica del Sándwich)
- **⚡ Análisis rápido (V6)** en < 2 segundos
- **🔬 Análisis forense (V5)** con Deep Scan
- **🤖 Watcher automático** para carpetas vigiladas
- **📊 Base de datos SQLite** unificada
- **📄 Informes PDF** por proyecto
- **✏️ Edición de metadatos** sin re-sellar
