## 🎤 Preparación de demostraciones

### 1. Prepara una imagen de ejemplo

**Recomendación:** Usar una imagen de alta calidad (un retrato o paisaje).

### 2. Muestra el proceso

1. **Seleccionar imagen** → 2 segundos.
2. **Rellenar metadatos** → 5 segundos.
3. **Sellar** → 10-30 segundos.
4. **Analizar** → 2 segundos (V6).

**Total:** Menos de 1 minuto.

### 3. Compara antes y después

- **Antes**: No hay rastro de autoría.
- **Después**: Sello forense detectado.

### 4. Muestra la resistencia

- **Redimensiona** la imagen sellada.
- **Recorta** una parte.
- **Comprime** a JPEG.
- **Analiza de nuevo:** El sello sigue ahí.
